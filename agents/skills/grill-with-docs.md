# Grill With Docs

Use this skill before substantial implementation, architecture changes, or ambiguous product work.

## Goal

Turn a loose idea into a defensible implementation direction by resolving the decision tree before writing production code.

## Process

1. Start with the outcome, constraints, and definition of success.
2. Inspect the codebase before asking questions it can answer.
3. Ask questions in dependency order, with a recommended answer and brief trade-off.
4. Mark unknowns honestly and use a prototype when measurement is required.
5. Stop when no important behavior, ownership, data flow, failure mode, or rollout assumption remains implicit.

## Completion

Finish with a concise decision record, the files that must change, the risks to test, and any remaining experiment or rollout gate.
